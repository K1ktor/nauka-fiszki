# Grafika postaci z easter egga

Wrzuć tu obrazek postaci jako `postac.png` (działa też `postac.webp`, `.gif`, `.svg`, `.jpg`),
najlepiej z przezroczystym tłem i postacią zwróconą w prawo, a potem zbuduj aplikację
(`npm run tauri build` albo wydanie przez GitHub Actions).

Bez tego pliku aplikacja pokazuje wbudowaną postać rysowaną w SVG (`src/components/EasterEgg.tsx`).
Pamiętaj, że obrazek trafi do repozytorium i do instalatora – nie wrzucaj grafik, do których nie masz praw,
jeśli repozytorium lub aplikacja są publiczne.
